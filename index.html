INTRODUCTION :

La bioinformatique occupe une place importante dans l'analyse des données biologiques, notamment dans l'étude des relations évolutives entre les organismes. Grâce aux outils informatiques et aux méthodes statistiques, il est possible de comparer des séquences d'ADN, d'identifier leurs similitudes et leurs différences, puis de reconstruire des arbres phylogénétiques permettant de représenter les relations de parenté entre différentes espèces.
Dans le cadre de ce travail pratique, nous allons étudier le gène codant l'ARN ribosomique 16S (16S rRNA) chez trois espèces bactériennes : Escherichia coli, Salmonella enterica et Klebsiella pneumoniae. Les séquences nucléotidiques seront récupérées dans la base de données GenBank, accessible par l'intermédiaire de la plateforme du National Center for Biotechnology Information (NCBI).
Après avoir vérifié et préparé les séquences, nous réaliserons des alignements globaux à l'aide de l'algorithme de Needleman–Wunsch. Nous calculerons ensuite les distances génétiques entre les espèces à partir des séquences alignées et reconstruirons deux arbres phylogénétiques, l'un par la méthode UPGMA et l'autre par la méthode Neighbor-Joining. Enfin, nous comparerons les arbres obtenus afin d'interpréter les relations évolutives suggérées par les données.

Présentation du gène 16S rRNA

Le gène 16S rRNA code l’ARN ribosomique 16S, un constituant essentiel de la petite sous-unité des ribosomes bactériens. Il est largement utilisé en phylogénétique grâce à sa présence chez les bactéries, à ses régions conservées et variables, ainsi qu’à sa disponibilité dans les bases de données comme GenBank. Les régions conservées facilitent l’alignement des séquences, tandis que les régions variables permettent d’identifier les différences génétiques entre espèces. Toutefois, sa forte conservation peut limiter la distinction entre certaines bactéries très proches.

Nous allons travailler avec les trois espèces suivantes :
- Escherichia coli (Bactérie fréquemment retrouvée dans le microbiote intestinal humain) l'espèce de comparaison.
- Salmonella enterica (Bactérie pouvant provoquer des infections chez l'être humain) pour étudier les similitudes génétiques avec E. coli.
- Klebsiella pneumoniae (Bactérie pouvant être responsable d'infections, notamment respiratoires et sanguines) pour étudier les distances génétiques avec les deux autres espèces.

2_ Recuperation, Identification et axtraction des sequences

La récupération des séquences a été réalisée à l'aide du module Entrez de la bibliothèque Biopython, qui permet d'interroger les bases de données du NCBI et d'en extraire les enregistrements nucléotidiques. Les séquences obtenues ont ensuite été examinées afin de vérifier l'identité des organismes, l'annotation du gène étudié et la longueur des régions récupérées.
Vérifier l'identité et la qualité des séquences du gène 16S rRNA chez les trois espèces, extraire les régions correspondantes et de les enregistrer dans un fichier FASTA nommé 16S_rRNA_only.fasta.

Script
from Bio import Entrez, SeqIO

Entrez.email = "regismnon@mail.com"

species = [ "Escherichia coli","Salmonella enterica","Klebsiella pneumoniae"]

# Fichier FASTA de sortie
output_file = "16S_rRNA_only.fasta"

sequences = []

# --------------------------------------------------
# 2. Recherche et extraction du gène 16S rRNA
# --------------------------------------------------
for sp in species:

    print(f"\nRecherche du gène 16S rRNA chez : {sp}")

# Recherche dans la base NCBI Nucleotide
    query = (f'"{sp}"[Organism] ' 'AND "16S ribosomal RNA"[Title]' )

    try:

        with Entrez.esearch(db="nucleotide",term=query, retmax=10) as handle:

            search_results = Entrez.read(handle)

        ids = search_results["IdList"]

        if not ids:
            print(f"Aucun résultat trouvé pour {sp}.")
            continue

        print(f"{len(ids)} enregistrements trouvés.")

# Récupération des enregistrements GenBank
        with Entrez.efetch(db="nucleotide",id=ids,rettype="gb",retmode="text") as handle:

            records = list(SeqIO.parse(handle, "genbank"))

# --------------------------------------------------
# 3. Identification et extraction du gène 16S rRNA
# --------------------------------------------------

        gene_found = False

for record in records:           # Vérifier l'organisme

            organism = record.annotations.get("organism", "")

            if sp.lower() not in organism.lower():
                continue

            for feature in record.features:

                if feature.type == "rRNA":

                    product = feature.qualifiers.get( "product", [""])[0]            # Vérifier qu'il s'agit du 16S rRNA

                    if "16S ribosomal RNA" in product:

                        gene_sequence = feature.extract(record.seq)      # Construire un enregistrement FASTA
                        fasta_record = SeqIO.SeqRecord(gene_sequence,id=sp.replace(" ", "_"),
                            description=(f"16S_rRNA accession={record.id}"))

                        sequences.append(fasta_record)

                        print("Séquence extraite avec succès.")
                        print("Accession :", record.id)
                        print("Longueur :",len(gene_sequence), "nucléotides")

                        gene_found = True
                        break

            if gene_found:
                break

        if not gene_found:
            print(f"Aucune annotation 16S rRNA exploitable "f"trouvée pour {sp}.")

    except Exception as e:
        print(f"Erreur pour {sp} : {e}")

# --------------------------------------------------
# 4. Enregistrement des séquences au format FASTA
# --------------------------------------------------

if sequences:
    SeqIO.write(sequences, output_file, "fasta")
    
    print("\nExtraction terminée.")
    print("Nombre de séquences obtenues :", len(sequences))
    print("Fichier créé :", output_file)

else:

    print("\nAucune séquence n'a pu être extraite.")

3_ Réaliser des alignements globaux avec Needleman–Wunsch.

Après l'extraction des séquences du gène codant l'ARN ribosomique 16S chez Escherichia coli, Salmonella enterica et Klebsiella pneumoniae, une étape d'alignement a été envisagée afin de comparer leurs séquences nucléotidiques. il permet de mettre en correspondance les positions homologues des séquences et d'identifier les différences nucléotidiques susceptibles de renseigner sur leur divergence évolutive.
Cet alignement sera réalisés à l'aide de l'algorithme de Needleman–Wunsch.
Cet algorithme réalise un alignement global, c'est-à-dire qu'il cherche à aligner les séquences sur toute leur longueur. Il repose sur la programmation dynamique et attribue un score aux correspondances (match), aux différences (mismatch) et aux insertions/suppressions représentées par des gaps (-). L'objectif est de trouver l'alignement ayant le meilleur score global. Dans notre étude, l'algorithme de Needleman-Wunsch sera appliqué aux séquences du gène 16S rRNA obtenues chez les différentes espèces.
Ainsi nous commencerons par effectuer les alignements deux à deux :
- Escherichia coli et Salmonella enterica ;
- Escherichia coli et Klebsiella pneumoniae ;
- Salmonella enterica et Klebsiella pneumoniae.

Les alignements serviront ensuite au calcul des distances génétiques, qui seront utilisées pour construire plus tard les arbres phylogénétiques

4_ Calcule d'une matrice de distances génétiques fondée sur la p-distance.

Une fois les alignements examinés, nous pourrons passer au calcul des distances génétiques.Nous utiliserons notamment la p-distance, qui correspond à la proportion de positions comparables présentant des nucléotides différents.
Sa formule est :

p = NdNc

où :
Nd représente le nombre de positions présentant des nucléotides différents ;
Nc représente le nombre total de positions comparables retenues dans le calcul.

Une p-distance de 0 signifie que les deux séquences sont identiques (hors gaps), tandis qu'une valeur proche de 1 indique qu'elles sont très différentes.

4-1_Calcul de la p-distance
Script
# selectionne le meilleur alignement global
def p_distance (seq1, seq2):
    alignment = aligner.align(seq1,seq2)[0]    #Le meilleur alignement global entre seq1 et seq2 est calculé à l'aide de l'outil aligner.
    aligned = alignment.format()                # extrait les sequences aligner
    lignes = aligned.split('\n')

    seqA = ""              # stocker les sequences dans seqA et seqB
    seqB = ""

    for line in lignes:
        if line.startswith("target"):
            seqA += line.split()[2]

        elif line.startswith("query"):
            seqB += line.split()[2]

    differences = 0
    compared = 0

    for a, b in zip(seqA, seqB):            #Les deux séquences alignées sont parcourues position par position.

        # on ignore les gaps
        if a == "-" or b == "-":           #les positions contenant un gap (-) ne sont pas prises en compte dans le calcul
            continue

        compared += 1

        if a != b:
            differences += 1

    return differences / compared          #La p-distance est obtenue en divisant le nombre de différences par 
                                              #le nombre total de positions comparées (hors gaps).

5_ Reconstruction des arbres phylogénétiques par UPGMA et Neighbor-Joining.

Un arbre phylogénétique représente les relations de parenté entre des espèces à partir de leurs caractéristiques génétiques. Les extrémités, appelées feuilles, correspondent aux espèces étudiées, tandis que les nœuds représentent leurs ancêtres communs hypothétiques. Les longueurs des branches peuvent représenter les distances évolutives entre les séquences, selon la méthode de reconstruction utilisée.

Pour décrire la structure d'un arbre, nous utilisons le format Newick, une notation textuelle standard en bioinformatique. Les parenthèses indiquent les regroupements entre les espèces. Par exemple, ((A,B),C); signifie que A et B partagent un ancêtre commun plus récent entre eux que celui qu'ils partagent avec C. Les longueurs des branches peuvent être indiquées après le symbole :. Ainsi, dans ((A:0.10,B:0.10):0.05,C:0.15);, les valeurs numériques représentent les longueurs des branches correspondantes.
Le format Newick permet donc de représenter simplement la topologie d'un arbre phylogénétique et, lorsqu'elles sont disponibles, les longueurs de ses branches.

Biopython utilise la classe DistanceMatrix; Cette classe permet de représenter une matrice de distances compatible avec les algorithmes de construction d'arbres phylogénétiques de Biopython, tels que Neighbor Joining (NJ) et UPGMA.

L’arbre UPGMA regroupe Salmonella enterica et Escherichia coli, qui partagent un ancêtre commun plus récent, tandis que Klebsiella pneumoniae se rattache ensuite. Cette topologie est globalement cohérente avec leur classification bactérienne. Toutefois, l’analyse repose sur un seul gène et la méthode UPGMA suppose une vitesse d’évolution constante entre les lignées. Ces limites doivent être prises en compte dans l’interprétation des relations évolutives.

L’arbre obtenu par la méthode Neighbor Joining relie les trois espèces à un même nœud interne, donnant une représentation en étoile. Avec seulement trois taxons, cette forme ne permet pas de mettre en évidence un regroupement bifurqué uniquement à partir de la topologie. Toutefois, les longueurs des branches indiquent que Escherichia coli et Salmonella enterica présentent la plus faible distance évolutive estimée. Contrairement à UPGMA, le Neighbor Joining ne suppose pas que toutes les lignées évoluent à la même vitesse.

Conclusion

Les arbres obtenus montrent que la méthode de reconstruction influence la représentation des relations génétiques. UPGMA regroupe Escherichia coli et Salmonella enterica, tandis que Neighbor Joining présente un arbre en étoile, même si les longueurs des branches indiquent que ces deux espèces sont les plus proches. Ces résultats doivent être interprétés avec prudence, car l’analyse repose sur un seul gène, le 16S rRNA, et seulement trois espèces. Pour obtenir une phylogénie plus fiable, il serait utile d’étudier davantage d’espèces et d’utiliser plusieurs marqueurs moléculaires.
